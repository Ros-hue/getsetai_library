# ARCHIVE01 — Private Digital Library

A dark futuristic React/Vite library UI with an animated credential gate.

## Run
```bash
npm install
npm run dev
```

## Demo access
- Library Token: `LIB-2026`
- Passkey: `LIBRARY`

> The credential check in this demo is client-side for UI prototyping only. For production, move authentication to a server/API and store passkeys securely (hashed), with rate limiting and session management.
